# gestopago_app

App Flutter de la plataforma de pagos GestoPago (Android, iOS y web).

```bash
flutter pub get
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:8091
flutter test
```

Arquitectura, servicios consumidos y escenarios de prueba: [docs/APP_FLUTTER.md](../docs/APP_FLUTTER.md).
